¿Cómo funciona este apartado? ▾
Este módulo se usa el día de la Asamblea, para registrar lo que va pasando durante el evento. Tiene 3 pasos, en orden:

1. Asamblea celebrada — cargá cuántos socios estuvieron y si hubo quórum. Es solo un registro, no afecta nada más.

2. Autoridades electas — acá es donde se define quién queda en cada cargo que se renueva. Por cada uno, marcás si fue reelecto/a (sigue el mismo) o escribís el nombre del nuevo titular. Al guardar, esto actualiza de verdad la base de Autoridades.

3. Acta de Asamblea — acá solo se usa lo que ya cargaste arriba (no lo vuelve a pedir). Tenés el Orden del Día a la vista para guiarte, escribís el resultado de cada punto, y la IA arma el Acta formal completa. Después la podés editar y, cuando esté lista de verdad, marcarla como Firmada.
